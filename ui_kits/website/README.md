# Website UI kit — しあわせの選び方

Recreation of the two supplied mockups (PC + smartphone top page).

- `index.html` — PC top page (`PcHome.jsx`): header (split nav + centered logo + coral arrow), wave-frame hero, intro with 3D pedestals, CHOOSE YOUR WAY lilac band, JOURNAL, compare peach band, FAQ, footer.
- `mobile.html` — SP top page in a 390×844 frame (`SpHome.jsx`): sticky header + hamburger drawer, hero, CHOICE intro, horizontal choice/journal/compare rows, chevron FAQ, mint wave footer.
- `data.js` — all copy (placeholder; dates & small text in the mockups are provisional).

Interactive: nav/CTA smooth-scroll to sections, FAQ accordions, SP menu drawer, hover states on cards/buttons.
Not in source → not built: category pages, comparison tables, diagnosis flow, article detail.
